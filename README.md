# <img width="50" height="50" align="center" alt="icon" src="https://github.com/user-attachments/assets/3740a7a0-b58d-411f-b13f-7d51b7c956c6" /> potato dumper. — репрайсер для Plati.Market

      Тебе надоело по тысячу раз на дню проверять все свои товары? У меня есть для тебя решение.

Инструмент для продавцов на площадке Plati.Market. Программа в реальном времени отслеживает цены конкурентов и автоматически корректирует ваши цены, чтобы вы всегда оставались на первой позиции в выдаче, сохраняя при этом заданную маржинальность.

![Version](https://img.shields.io/badge/version-2.0-brightgreen)
![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-blue)
![Status](https://img.shields.io/badge/status-stable-success)

---

*   **`Умная авто-цена:`** Автоматически находит лидера на рынке по заданным условиям и ставит вашу цену на шаг ниже. Продаете слишком дешево? Программа повысит цену. Слишком дорого? Опустит в пределах порога.
*   **`Защита от убытков:`** Вы задаете жесткий **минимальный лимит**, ниже которого цена никогда не опустится. Работа в минус исключена.
*   **`Фильтр конкурентов:`** Возможность игнорировать продавцов с низким количеством продаж.
*   **`Массовое управление:`** Поддержка любого количества товара.
*   **`Безопасность:`** Работает через официальное API Digiseller.
*   **`Скорость:`** Обрабатывает 1000 товаров за ≈70 секунд! (при 32 потоках)

## ⚙️ Настройка

> #### 1. Получение ключей
Для работы программы требуются ключи доступа.
1. Зайдите в личный кабинет на [my.digiseller.com](https://my.digiseller.com).
2. Скопируйте `идентификатор` (seller_id). <br>

<img width="432" height="144" alt="image" src="https://github.com/user-attachments/assets/a15f8698-c3ba-4ea7-b44c-1347c7170602" /> <br>
3. Перейдите в раздел **Магазин** -> **API**. <br>
4. Создайте новый `ключ` (api_key) <br>

<img width="435" height="160" alt="image" src="https://github.com/user-attachments/assets/69b09bfe-fffc-48c8-92af-17da8c0fcb01" />

> #### 2. Настройка товаров
1. Запустите программу.
2. Откройте **Настройки** и введите ранее скопированные данные.
3. Укажите количество потоков - чем больше, тем быстрее работает программа, но есть шанс на блок API вызовов. (идеальное значение = 5-10)
4. Нажмите **`cохранить`** — программа загрузит список ваших активных товаров.
5. Для каждого товара, который вы хотите мониторить укажите:
    *   Ссылку на категорию или на поиск. Примеры:
   ```
   https://plati.market/games/nintendo-eshop/1056/?id_c=4010
   ```
   ```
   https://plati.market/search/RUNESCAPE%20DRAGONWILDS%20steam%20gift
   ```
    *   **Мин. цену** (ниже неё цена не упадет).
    *   Фильтр количества продаж
    *   Шаг для демпинга
5. Нажмите **`cтарт`** для запуска автоматического цикла.
